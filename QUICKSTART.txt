--------------

TROUBLESHOOTING:
----------------

Error: "nvcc: command not found"
 Install CUDA: sudo apt install nvidia-cuda-toolkit

Error: "Driver/library version mismatch"
 Reboot: sudo reboot
 Or reinstall drivers: sudo ubuntu-drivers autoinstall

Error: "compute_XX is not defined for option 'gpu-architecture'"
 Your GPU is too old. Edit Makefile, change GPU_ARCH to lower value (e.g., 61)

Compilation errors:
 Try debug build: make DEBUG=1
 Check CUDA version: nvcc --version
 Ensure GCC version is compatible (GCC 7-11 recommended)

SCALING TO 256-BIT:
-------------------
To scale from 16-bit to full BN254 (256-bit):
1. Edit include/bn254_types.cuh:
   - Change LIMB_BITS to 64
   - Change NUM_LIMBS to 4
   - Update FIELD_MODULUS to full BN254 prime
2. Implement full multi-limb arithmetic in src/field_ops.cu
3. Recompute Montgomery constants
4. Rebuild and test
